# Football Director

ブラウザだけで遊べる、日本語の架空クラブ・架空選手によるサッカー監督・クラブ経営シミュレーションです。

日本1部・2部・3部の合計60クラブと全国王者杯を舞台に、編成、戦術、育成、移籍、財務、選手の不満・衰え・引退までを管理し、長期キャリアを戦います。実在クラブ、実在選手、実在大会名、ライセンス画像は使用していません。

## 主な機能

| 分野 | 実装内容 |
|---|---|
| 新規キャリア | 1～3部の既存60クラブから選択、またはオリジナルクラブを設立して3部から開始 |
| リーグ | 日本1部・2部・3部、各20クラブ、各部38節、毎季3クラブ昇格・3クラブ降格 |
| カップ戦 | 全60クラブ参加、6ラウンド制の全国王者杯 |
| 試合 | 2Dサッカー盤、前半・60分・75分の判断停止、試合中戦術、手動・自動交代、xG、実況、選手評価、MOM |
| 戦術 | 5フォーメーション、試合中指示、リード・同点・ビハインド別プラン、交代開始時間・体力基準・優先条件 |
| スカッド | ドラッグ配置、固定起用、個別交代方針、主将・PK、性格・信頼、面談・約束、ソート・絞り込み |
| 選手人生 | 成長、衰え、引退表明、引退、不満理由、幸福度、移籍希望、契約更新 |
| AIクラブ | 若手育成、弱点補強、部門別の予算運用、昇降格後の戦力更新 |
| 育成 | 週間トレーニング、ユース昇格、8週ごとのユース新加入 |
| 移籍 | 6地域の知識、候補リスト、クラブ間交渉、代理人交渉、レンタル、売却・契約解除 |
| 経営 | 8軸の理事会評価、シーズン目標、9職種のスタッフ市場、予算配分、施設・継続投資 |
| 記録・監督 | 監督評判・レベル・通算成績、他クラブオファー、個人成績、タイトル、退団・引退履歴 |
| 秘書 | 次戦、負傷、疲労、不満、契約、予算を整理した週間レポート |

## 新規キャリア

### 既存クラブ

日本1部・2部・3部の60クラブから選択します。上位部門では優勝争い、下位部門では昇格を目標にできます。

### オリジナルクラブ

クラブ名、本拠地、クラブカラー、クラブ方針を設定します。新設クラブは日本3部の1枠と入れ替わり、3部水準の戦力・評判・予算から開始します。

## シーズン構成

- リーグ戦：各部ホーム＆アウェー38節
- 全国王者杯：6ラウンドの一発勝負
- シーズンカレンダー：44週
- 昇降格：1部・2部の下位3クラブが降格、2部・3部の上位3クラブが昇格

## 長期キャリア

- 選手は毎季加齢し、若手は成長、高齢選手は能力が衰えます。
- 引退予定の選手は受信トレイとスカッドで通知されます。
- 出場機会、契約、士気などから幸福度と不満理由が変化し、深刻な場合は移籍希望を提出します。
- AIクラブもシーズン間に補強・育成を行うため、長期的に競争環境が変化します。
- 現金から移籍予算へ資金を配分でき、施設完成後も医療、分析、商業、地域活動、スタジアムへ継続投資できます。

## 操作

- ピッチ上の選手同士、または選手一覧からピッチへドラッグして先発を変更できます。
- スカッド画面を下へスクロールしても、PCではフォーメーションカードが追従します。
- フォーメーション上部の選択欄から、その場でシステムを変更できます。
- キャプテンは `C`、PKキッカーは `PK` のバッジで表示されます。
- 選手一覧は起用状況、ポジション、OVR、POT、体力、士気、年齢、給与、名前で整理できます。
- 「試合を開始」すると2Dサッカー盤の試合センターが開き、前半終了、60分、75分で停止します。
- 停止中はフォーメーション、姿勢、プレス、テンポ、パス、守備ライン、攻撃重点、幅を変更できます。
- 先発とベンチを選んで手動交代でき、試合プランでは負傷、警告、疲労、低評価、主力温存、若手優先を設定できます。
- 「自動進行」は試合週を連続処理し、判断イベント、重要なカップ戦、シーズン終了、エラー、手動操作で停止します。
- スマホでは下部の「ホーム・試合・スカッド・移籍・メニュー」で主要操作へ移動し、ホームの固定ボタンから次の試合へ進めます。
- 売却、契約解除、獲得、投資、リセットの確認にはブラウザ標準ダイアログを使わず、ゲーム内モーダルを使用します。

## クラウドセーブ

ゲーム内の「クラウドへ保存」「クラウドから読み込む」から、3～32文字のIDと8文字以上のパスワードを入力します。1アカウントにつき最新セーブ1枠、上限4 MiBです。

- パスワード: PBKDF2-SHA-256、120,000回
- セッション: HttpOnly / Secure / SameSite=Lax Cookie
- ログイン保護: 5回失敗で15分ロック
- 保存先: Cloudflare D1

Cloudflare側の設定は [`docs/cloud-save-setup.md`](docs/cloud-save-setup.md) を参照してください。

## 必要環境

- Node.js 22以上
- Chrome、Edge、Firefox、Safariの現行版

通常プレイは外部API・外部画像・ランタイム依存パッケージなしで動作します。クラウド保存を使用する場合のみ、Cloudflare Pages FunctionsとD1データベースが必要です。

## 起動方法

```bash
npm run dev
```

ブラウザで次を開きます。

```text
http://127.0.0.1:4173
```

ポートを変更する場合:

```bash
PORT=8080 npm run dev
```

## 検証コマンド

```bash
npm test
npm run check
npm run smoke
npm run verify
npm run build
```

| コマンド | 内容 |
|---|---|
| `npm test` | ゲームロジック、UIレンダリング、複数シーズン統合テスト |
| `npm run check` | JavaScript構文、相対import、HTML必須要素、未完了表記、ブラウザ標準ダイアログ不使用を検査 |
| `npm run smoke` | ローカルサーバーの主要5ルートをHTTP確認 |
| `npm run verify` | テスト、品質検査、スモーク検査をまとめて実行 |
| `npm run build` | Cloudflare Pages向けの`dist/`を生成 |

## 設計上のポイント

- ゲームルールをDOMから分離し、同一シード・同一操作で結果を再現します。
- 60クラブ・約1,300選手の長期キャリアを保存できるよう、セーブデータを圧縮しています。
- 詳細な試合レポートは自クラブ戦を中心に保存し、ブラウザ容量の肥大化を抑えます。
- 状態変更は原則として複製後に行い、失敗時は元の状態を返します。

## 現バージョンの対象外

- 実在クラブ・選手・リーグ
- オンライン対戦
- 連続アニメーション型の3D試合描画
- 課金アイテム・決済
- 代表チーム、国際クラブ大会
