# コードレビュー報告

実施日: 2026-07-26

## 結論

重大または高優先度の未修正事項はありません。ゲーム状態、試合ロジック、経営処理、保存、レスポンシブUIを対象にセルフレビューし、検出した不整合は修正済みです。

| 状態安全性 | 失敗操作で元状態を破壊しない、セーブ検証 | 問題なし |

| 保存 | localStorage、JSON入出力、スキーマ検証 | 問題なし |

## レビューで検出・修正した項目

| 重要度 | 検出内容 | 修正内容 | 回帰テスト |
|---|---|---|---|
| 高 | 難易度補正の除外対象が初期クラブに固定される可能性 | 選択したクラブIDをリーグ生成へ明示的に渡す | 追加済み |
| 高 | 選手獲得後に移籍市場価格を削除すると財務台帳額がずれる可能性 | 削除前に合意移籍金を退避して台帳へ記録 | 追加済み |
| 高 | 支出イベントで現金がマイナスになり得る | 選択確定前に資金不足を拒否 | 追加済み |
| 中 | スマホメニューで後半項目が表示しづらい | 全8項目を横スクロールで利用可能に変更 | UIレンダリング確認 |
| 中 | 設計に対して契約解除が不足 | 12週分給与を補償金とする契約解除を追加 | 追加済み |
| 中 | 設計に対して定期ユース加入が不足 | 4週ごとに2人の候補を生成し受信トレイへ通知 | 追加済み |
| 中 | 実況に交代イベントが不足 | 両チーム1〜3人の自動交代を追加 | 追加済み |
| 中 | 1シーズン終了後に進行不能 | 次シーズン開始、年齢・成績リセット、日程再生成を追加 | 追加済み |

## 保守性

- `src/game`はDOM非依存のES Moduleです。
- `performAction`を操作の共通入口にして、UIからゲーム状態への直接変更を避けています。
- 乱数はシード付きで、テストの再現性を確保しています。
- 保存形式に`schemaVersion`を持たせ、未知バージョンを拒否します。
- 外部ライブラリがなく、依存更新による破損リスクを抑えています。

## 残存する制約

- 実ブラウザの画像比較テストは含めていません。UIは文字列レンダリングテストとHTTPスモークテストで検証しています。
- 複数部制、昇降格、カップ戦、契約更新交渉は未実装です。
- localStorage保存のため、端末間同期はできません。
- 試合は統計・実況型で、ピッチ上の選手移動描画はありません。
