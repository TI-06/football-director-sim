# コードレビュー報告

実施日: 2026-07-28
対象: 第3～5弾統合アップデート、固定起用、クラウドセーブ、PC・スマートフォンのレスポンシブ最適化

## 結論

重大・高優先度の未修正事項はありません。レスポンシブ対応ではゲームロジックとセーブ形式を変更せず、共通シェル、CSS、表示順、モバイル専用配置座標、実ブラウザ監査だけを変更しています。

## レスポンシブ対応で修正した主な問題

- 1366×768で中央領域を圧迫していた238px・300pxの左右レールを216px・264pxへ縮小。
- ダッシュボードの主要クイック操作を初期表示内へ移動。
- 1120px以下でアイコンサイドバーへ切り替え、1280px未満で右パネルを非表示化。
- スマートフォンの横スクロール式ナビを5等分固定グリッドへ変更。
- 表の横スクロールを`.table-wrap`内部だけに限定。
- モバイルダイアログをヘッダー・本文スクロール・操作領域の3段構成へ変更。
- 320px幅で重なったフォーメーションカードを5段階のモバイル専用行へ再配置。
- E2Eが存在しない戦術カテゴリを探していた誤りを、実際のダッシュボード導線へ修正。

## 既存機能で修正した主な不具合

- 自チーム評価点を区間単位で上書きしていた処理を、出場時間加重の累積へ変更。
- 得点・アシストの評価加点がイベント時と終了時に二重加算される問題を除去。
- シーズン目標を切り替えるたび移籍予算が複利増加する問題を、シーズン開始時予算基準へ固定。
- 固定先発が低体力でも無条件で先発する問題を、体力55未満では控え固定相当に変更。
- 自動進行が期限付き約束、理事会警告、監督オファー、交渉、ダービーを通過する問題を修正。
- 新規クラウドID登録直後にセッションがなく保存できない問題を、登録後ログインへ統一。
- 監督移籍時に旧クラブの理事会・スタッフ・約束・スカウト状態が残る問題を、新クラブ状態へ切替。
- 地域別視察ボタンが全地域で同一選手を参照する問題を、地域適合候補の選択へ修正。

## 残存制約

- 2D試合は区間進行型で、連続物理演算型ではありません。
- クラウド保存はCloudflare Pagesへ`GAME_DB` D1バインディングを設定した環境でのみ利用できます。
- 旧セーブ互換は対象外で、schema version 3の新規キャリアを前提とします。
- スマートフォンでは情報量の多い表だけ、カード内部の横スクロールを許可します。
