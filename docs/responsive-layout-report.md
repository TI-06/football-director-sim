# レスポンシブ画面監査報告

実施日: 2026-07-28
対象PR: #19

## 結論

PC・タブレット・スマートフォンの主要画面を実Chromiumで監査し、ページ全体の横はみ出し、画面外へ押し出される主要操作、スマートフォンの小さすぎる操作領域、固定UIの干渉を解消しました。

最終監査では7ビューポートすべて成功し、320×568を含むスマートフォンのスカッド配置でも選手カード同士の重なりはありません。

## 対象画面

- 新規ゲーム
- ダッシュボード
- 試合日程
- スカッド・固定起用
- 戦術・セットプレー
- 移籍・スカウト
- クラブ・スタッフ・理事会
- 記録・監督キャリア
- ライブ試合
- クラウド保存ダイアログ

## 自動検査

- `document.documentElement.scrollWidth <= clientWidth`
- 表など許可された内部スクロール領域以外の横はみ出しがない
- 主要ボタン、カード、ヘッダー、固定ナビが画面外へ押し出されない
- スマートフォンの下部ナビが5項目すべて画面幅内に収まる
- スマートフォンの主要操作領域が44×44px以上
- スマートフォンのフォーメーションカード同士が交差しない
- ダイアログの閉じる・決定操作へ到達できる
- JavaScript例外とコンソールエラーがない

## 検出して修正した問題

1. 1366×768では左238px・右300pxの3カラムにより中央領域が狭かったため、左216px・右264px・トップバー64pxへ調整しました。
2. 主要クイック操作がダッシュボード下部にあり初期表示から外れていたため、指標直下へ移動しました。
3. スマートフォンの下部ナビが横スクロール式だったため、5等分固定グリッドへ変更しました。
4. 一部の小型ボタンが44px未満だったため、スマートフォンの主要操作領域を統一しました。
5. 320px幅でDMとAMなどの選手カードが約2.5px重なったため、モバイル専用の5段階配置行へ変更しました。
6. 実際には存在しない戦術カテゴリをE2Eが直接探索していたため、ダッシュボードの試合プラン導線を使う実操作へ修正しました。

## CI

GitHub Actionsの`Responsive layout audit`で、単体テスト、品質検査、HTTPスモーク、production build、7ビューポートのChromium監査を実行します。失敗時はスクリーンショット、trace、HTMLレポートを保存し、通常実行でも監査用スクリーンショットを14日間保持します。
