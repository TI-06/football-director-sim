# スマホゲーム全面刷新 実装報告

実装日: 2026-07-31  
対象: `TI-06/football-director-sim`

## 実装内容

| 項目 | 内容 |
|---|---|
| 初期画面 | ホーム／ダッシュボード |
| スマホナビ | ホーム・試合・編成・移籍・メニュー |
| キャラクター | ミナ・ソータ・レイ・カズオを正式レンダリングへ統合 |
| ホーム | 次戦、要対応、順位、戦力、体力、士気、予算、最近の結果 |
| 試合 | スマホ縦型フルコート、○・●、背番号常時表示 |
| 試合の動き | 計算済みイベントに関係する選手だけCSSアニメーション |
| 選手確認 | 背番号タップで名前、ポジション、体力、評価、状態を表示 |
| 試合介入 | ハーフタイム、60分、75分、負傷等の既存フェーズを維持 |
| 編成 | ドラッグ操作に加え、スマホで選手タップ→配置先タップを追加 |
| セーブ | ローカルキーと保存スキーマをv4へ分離、旧形式を明示的に拒否 |
| 軽量化 | 試合中は画像を使わず、22個の円形DOM要素とボールで描画 |
| アクセシビリティ | 44px操作領域、背番号・ARIA名称、reduced-motion対応 |

## アーキテクチャ

- 既存のゲーム計算・リーグ・移籍・育成・財務ロジックは維持する。
- 新しいレンダリング層を`render-v2.js`へ分離する。
- 既存の詳細画面は機能を維持しながら、新しいシェルとデザインでラップする。
- 試合表示モデルは試合計算結果を変更せず、視覚表現だけを生成する。
- 旧キャラクター後付けスクリプトはHTMLから除外した。
