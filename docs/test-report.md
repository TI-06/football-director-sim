## 手動確認推奨項目

1. スマホ幅で下部に「ホーム・試合・スカッド・移籍・メニュー」の5操作が表示されること。
2. メニューを開き、戦術、記録、秘書、クラブ経営、受信トレイへ移動できること。
3. ホームの固定ボタンから試合を開始できること。
4. 前半、60分、75分で試合が停止し、戦術変更と手動交代が反映されること。
5. フルタイム時にだけ週、順位、財務、個人成績が更新されること。
6. 売却、契約解除、獲得、施設投資、リセットでゲーム内確認モーダルが表示されること。
7. ブラウザ再読み込み後に確定済みの最新セーブから復元されること。
